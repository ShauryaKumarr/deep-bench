# Deep Bench

A daily football quiz. Seven prompts a day, 25 seconds each:

- *Played for Barcelona and Lazio*
- *Played for PSG, from Brazil*
- *A goalkeeper who played for Chelsea*
- *A player from Türkiye who played in La Liga*

Type any player who fits. Wrong guesses cost nothing, so keep going until the clock runs out; your first correct answer locks in. Every correct answer scores, but obscurity pays: the best-known valid answer is worth 10m and the least known 100m, with everything in between ranked by fame. Your total depth (max 700m) places you in the English football pyramid, from the Premier League (0m) down to Sunday league (590m+).

Leaving the page while the clock is running counts that round as a miss.

## Development

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check and build to dist/
```

The game is a static Vite + TypeScript site with no framework. Progress, streaks and stats live in `localStorage`.

All the pixel art is drawn in code on low-resolution canvases (`src/pixel/`), with no image files:

- **Grounds** (`ground.ts`): one stadium per pyramid level, from a floodlit double-tier bowl to a wet park with a dog. The page background shows the ground for your current depth.
- **Replays** (`cutscene.ts`): after each round a short goal plays, matched to the emoji grid. 🟩 is a tap-in, 🟧 a curler, 🟥 an overhead-kick worldie with fireworks, and ⬛ a shot off the bar. Dropping a division adds a dig down through the turf to the next ground. Click or press any key to skip; they're skipped entirely with reduced motion.
- **Full time** (`fulltime.ts`): after round seven, the referee blows up, your total counts in, and the division you finished in gets a send-off to match: polite applause near the top, fireworks in non-league. It can be rewatched from the results screen.
- **Sound** (`src/sound.ts`): whistle, kick, net, crowd, groans, fireworks and 8-bit jingles, all synthesised with the Web Audio API (no audio files). Off by default; the speaker button in the corner turns it on and the choice is remembered.

## Data

`public/data/` is generated by `scripts/build_data.py` (Python 3 with pandas):

```sh
python3 scripts/build_data.py                      # 730 days from 2026-11-17
python3 scripts/build_data.py --start 2027-01-01 --days 365
```

The script shallow-clones both source repositories into `.cache/` (skipping their Git LFS files) and writes:

- `players.json`: every player, ordered from most to least famous, with nationality, position group and first/last season for disambiguation.
- `days/YYYY-MM-DD.json`: seven prompts per day, each with its valid answers ordered by fame.

How it works:

- **Clubs.** A player played for a club if they appear in that club's transfer records (the `club` column), in or out, loans included. Club name variants are merged ("Parma FC", "AC Parma" and "Parma Calcio 1913" are all Parma) and shortened for display.
- **Fame** = 0.55 × log-scaled peak value + 0.45 × min(caps, 120) / 120. Peak value is the highest market value or transfer fee on record, with pre-2019 money scaled by 2^((2019 − year) / 5.5). Caps are senior international appearances; the source mixes youth sides in without naming them, so each nation's senior side is taken to be the team its players were capped for most in total.
- **Prompts** use only the 60 most famous clubs, need 6 to 250 valid answers and at least two well-known ones (in the 1,500 most famous players), and never repeat within 150 days.

## Deployment

Deployed on Vercel (`vercel.json`): build command `npm run build`, output directory `dist`. The generated data is committed, so deploys don't need Python.
